## Project Overview

Reconstructed and validated an earlier University of North Texas analytics project focused on predicting residential property sale values.

The original coursework used Python to compare interpretable linear regression models with nonlinear ensemble tree methods using residential property data associated with Iowa State University in Ames, Iowa.

For the portfolio version, the original analytical workflow was preserved, made portable, executed from a clean environment, validated end to end, and documented with portfolio-ready visualizations.

## Project Objectives

The reconstruction focused on:

- preserving the analytical scope of the original coursework;
- rebuilding the notebook so it could execute from repository-relative paths;
- validating the original data-preparation and modeling workflow;
- comparing regression and ensemble approaches using the original evaluation metrics;
- documenting model-performance trade-offs rather than forcing a single universal winner;
- regenerating key visualizations for portfolio presentation; and
- preserving the validated analytical workflow in a public Git repository.

## Data Preparation

The source workbook contained residential property transactions from multiple U.S. college-town markets.

The original project narrowed the analysis to properties associated with **Iowa State University in Ames, Iowa**, producing a working dataset of **211 residential transactions**.

The final modeling workflow used:

- `Beds`
- `Baths`
- `Sqft_home`
- `Sqft_lot`
- `Type`
- `Age`

The target variable was:

**`Sale_amount`**

Property `Type` was converted to a binary Single Family / Non-Single Family indicator, while `Age` was derived from `Build_year`.

The analysis also evaluated skew in the target and predictor distributions and introduced logarithmic transformations in the strongest linear-regression specification.

## Sale Price Distribution

The Ames sale-price distribution is strongly right-skewed, with a relatively small number of high-value properties extending well beyond the center of the distribution.

This pattern helped motivate the use of logarithmic transformations in the third regression model.

## Modeling Workflow

The project compared three Ordinary Least Squares regression specifications with three ensemble-tree approaches.

### Linear Regression

**Model 1**

`Sale_amount ~ Beds + Baths + Sqft_home + Sqft_lot + Type + Age`

**Model 2**

`Sale_amount ~ Baths + Sqft_home + Sqft_lot + Age`

**Model 3**

`log(Sale_amount) ~ Baths + log(Sqft_home) + log(Sqft_lot) + Age`

Model 3 introduced logarithmic transformations to better account for skew in the sale-price and square-footage variables.

### Ensemble Models

The ensemble analysis evaluated:

- a Bagging-style tree ensemble;
- Random Forest; and
- Gradient Boosting.

The ensemble workflow used a **70/30 train-test split** with a fixed random state for reproducibility.

Hyperparameter tuning was performed with **10-fold GridSearchCV** using negative Root Mean Squared Error as the scoring criterion.

## Feature Importance

Random Forest identified **home square footage** as the dominant predictor in the ensemble analysis.

Bathrooms, lot size, and property age also contributed meaningfully, while bedrooms and the simplified property-type indicator were less influential.

## Data Validation & Analytical Limitations

The reconstruction confirmed the original analytical workflow while also highlighting several limitations that are important when interpreting the results.

The analysis used only **211 observations from Ames, Iowa**, so the results should not be interpreted as a nationally generalizable residential valuation model.

Additional limitations include:

- the relatively small modeling sample;
- simplification of property type into a binary indicator;
- linear-model assumptions including possible multicollinearity;
- sensitivity to highly priced observations and skewed variables; and
- the interpretability trade-off between conventional regression and ensemble models.

The source workbook contains additional college-town markets, but expanding the analysis beyond Ames would constitute new analytical development rather than reconstruction of the original coursework.

That extension has therefore been reserved for a future project release.

- separation of public portfolio artifacts from original course-provided and group source materials.
